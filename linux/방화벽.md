centos는 firewalld를 사용.

```sh
sudo cat /etc/*release* // OS버전확인
firewall-cmd --state // 방화벽 상태확인
sudo yum install firewalld // 방화벽 설치
sudo systemctl enable firewalld // 서버 재부팅시 데몬 자동 실행
sudo systemctl start firewalld // 방화벽 가동
sudo firewall-cmd --permanent --add-service=http // 서비스로 화이트리스트 추가
sudo firewall-cmd --permanent --remove-service=http // 서비스로 화이트리스트 제거

sudo firewall-cmd --permanent --add-port=80/tcp // 포트로 화이트리스트 추가
sudo firewall-cmd --permanent --add-remove=80/tcp // 포트로 화이트리스트 제거
sudo firewall-cmd --permanent --add-port=6000-9000/tcp // 포트 구간으로 화이트리스트 추가

// 특정 IP에 대해서만 블랙리스트 추가 및 제거
sudo firewall-cmd --permanent --add-rich-rule='rule family="ipv4" source address=19 2.168.0.100 reject' // 피드백 보내줌
sudo firewall-cmd --permanent --add-rich-rule='rule family="ipv4" source address=19 2.168.0.100 drop' // 피드백 없음

sudo firewall-cmd --permanent --remove-rich-rule='rule family="ipv4" source address= 192.168.0.100 reject '#--> 피드백 보내줌
sudo firewall-cmd --permanent --remove-rich-rule='rule family="ipv4" source address=1 92.168.0.100 drop' #--> 피드백 없음

sudo firewall-cmd --reload // 변경한 firewalld 설정 적용

firewall-cmd --list-all // 현재 방화벽 리스트 보기
```

**netstat -ntl**
기존 서버가 방화벽을 사용하고 있지 않을 수 있음.
방화벽 화이트리스트에 사용할 포트가 명시되어 있지 않으면 서비스에 접속하지 못할 수 있음.
netstat -ntl명령어를 사용해서 서버에서 어떤 포트를 사용하고 있는지 확인하고 명시가 필요.

- **`-n` (Numeric):** 호스트 이름이나 포트 이름을 숫자로 표시합니다.
    
    - 예: `http` 대신 `80`, `localhost` 대신 `127.0.0.1`로 보여주어 속도가 빠르고 직관적입니다.
        
- **`-t` (TCP):** **TCP 프로토콜**을 사용하는 연결만 보여줍니다. (웹, 데이터베이스 연결 등 대부분의 서비스가 해당함)
    
- **`-l` (Listening):** 현재 연결된 상태가 아니라, 외부로부터의 연결을 **기다리고 있는(Open된)** 포트만 보여줍니다.
- **-p (Process):** 포트를 어떤 프로세스가 점유하고 있는지 확인할 수 있음.

| **항목**              | **의미**                                                          |
| ------------------- | --------------------------------------------------------------- |
| **Proto**           | 프로토콜 종류 (주로 tcp)                                                |
| **Local Address**   | **내 컴퓨터의 IP와 열려 있는 포트 번호** (예: `0.0.0.0:80`은 모든 IP에서 80번 포트 허용) |
| **Foreign Address** | 연결된 상대방의 주소 (Listening 상태에서는 보통 `0.0.0.0:*`로 표시됨)               |
| **State**           | 상태 (포트가 열려 있다면 반드시 **LISTEN**으로 표시됨)                            |

우분투는 ufw를 사용.
```sh
sudo ufw status // 방화벽 상태 확인
sudo ufw status numbered // 방화벽 현재 리스트 확인
sudo ufw status verbose // 자세한 정보 확인
sudo ufw allow 80 // 특정 포트만 허용
sudo ufw allow 443/tcp // 특정 프로토콜 지정
sudo ufw allow ssh // 특정 서비스 이름으로 허용
sudo ufw allow/deny from 192.168.1.100 to any port 3306 // 특정 아이피에서 허용/차단
```
