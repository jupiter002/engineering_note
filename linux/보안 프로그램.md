mod_evasive : apache웹 서버 모듈. 실시간으로 DoS, DDos, Brute Force공격들에 대해서 의심되는 패턴을 감지해서 공격IP를 차단.

	클라이언트가 일정시간안에 과도한 요청을 하면 일시적으로 IP를 블
	랙리스트에 추가해서 차단한다.
	1.apache인스턴스 별로 독립 인스턴스를 생성해 실시간 모니터링
	2. 같은 페이지에 대해 연속 요청: 기본 1초 간격내에 기본 2회 이
	상 요청시
	동시 요청: 같은 자식 프로세스에서 1초내에 기본 50회 이상 요청시
	두 조건중 하나를 만족하면 일시적으로 차단
	3.응답 코드 403을 반환, 블랙리스트에 추가, 기본 10초동안 모든 요청을 차단(공격중에 타이머
	가 재설정됨. 장기차단 유지)
	로그기록 /var/log/mod_evasive또는 지정된 디렉토리에 IP, 공격
	유형 저장
	4.이메일 알림: IP가 블랙리스트에 추가될때 지정한 이메일에 발
	송, 중복 알림 방지
	IP영구 차단: DOSSystemCommand를 사용하면 영구차단 가능	
	화이트 리스트: DOSWhitelist를 설정, 신뢰IP설정 가능

fail2ban : Brute Force차단 주로 사용. 로그 파일을 실시간으로 분석, 설정된 패턴을 감지해서 방화벽 규칙을 업데이트해서 공격IP를 차단.

	1.로그 모니터링: 다양한 서비스 로그를 실시간으로 설정된 패턴
	을 사용해서 분석 및 감지
	2.IP차단: 일정 횟수 이상 실패를 감지하면 의심IP를 방화벽 규칙
	에 추가
	3.패턴설정: 정규식을 사용해서 특정 포트, 프로토콜, 상태코드를 
	감지 규칙으로 설정 가능
	4.이메일 알림: 이벤트 발생시 이메일 또는 기타 알림으로 설정한 
	메신저로 알림가능

	주요 구성 요소
	1. jail: 특정 서비스(예: SSH, HTTP)를 보호하기 위한 
	설정 단위. 각 jail은 모니터링할 로그 파일, 필터, 액션을
	정의.
	2.filter: 로그에서 특정 패턴을 감지하기 위한 정규 표현식 파일.
	3.action: 감지된 위협에 대해 취할 조치(예: IP 차단, 알림 
	전송).
	4.bantime: IP가 차단되는 시간.
	5.maxretry: 차단 전 허용되는 최대 실패 시도 횟수.
