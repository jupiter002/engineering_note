20260303 선병원 스팸봇 자동 포스팅 차단을 목적으로 설치하면서 기록


1. ssh port변경
	sudo vi /etc/ssh/sshd_config -> Port 22를 다른걸로 변경 20022
	포트 변경후 ssh재시작 sudo systemctl restart ssh
	선병원은 우분투 24.04버전으로 ssh소켓 기반 활성화가 되어 있어, 서비스 재시작만으로는 포트 변경 적용이 되지 않음.
	
	소켓 설정 수정을 위해 디렉토리 생성
	sudo mkdir -p /etc/systemd/system/ssh.socket.d
	
	포트 오버라이드 파일 생성 후 변경할 포트번호 입력
	sudo nano /etc/systemd/system/ssh.socket.d/listen.conf
	[Socket]
	ListenStream=
	ListenStream=2200

	설정 반영 및 재시작
	sudo systemctl daemon-reload
	sudo systemctl restart ssh.socket
	변경 정보 확인
	sudo ss -tulpn | grep ssh
	systemctl status ssh

	추가한 포트의 방화벽 추가
	sudo ufw allow 20022/tcp

	클라우드 인바운드 규칙 추가

2. cowrie설치 및 환경 설정
	의존성 설치
	sudo apt update
	sudo apt install git python3-pip python3-venv libssl-dev libffi-dev build-essential libpython3-dev python3-minimal authbind -y

	사용자 생성
	sudo adduser --disabled-password cowrie
	
	Changing the user information for cowrie
	Enter the new value, or press ENTER for the default
	질문이 나오면 넘김

	사용자 cowrie로 변경
	sudo su - cowrie

	cowrie소스 코드 다운로드 가상환경 설정
	git clone http://github.com/cowrie/cowrie
	cd cowrie
	python3 -m venv cowrie-env
	source cowrie-env/bin/activate
	pip install --upgrade pip
	pip install -r requirements.txt

	설정 파일 구성
	cd etc
	cp cowrie.cfg.dist cowrie.cfg
	vi cowrie.cfg
	hostname : 공격자에게 보여줄 가짜 서버 이름
	listen_endpoints : cowrie는 기본 2222포트 사용
	
3. 포트 리다이렉션 22 -> 2222
	sudo iptables -t nat -A PREROUTING -p tcp --dport 22 -j REDIRECT --to-port 2222
	
	재부팅 후에도 유지하는 명령어
	sudo apt install iptables-persistent
	sudo netfilter-persistent save
	
4. cowrie실행 및 로그 확인
	# cowrie 사용자로 접속 중인 상태에서
	bin/cowrie start

스팸봇 활동 모니터링
tail -f var/log/cowrie/cowrie.log
