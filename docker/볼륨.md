컨테이너가 삭제되어도 데이터를 영구 보존하기 위한 독립 스토리지

볼륨과 마운트
	볼륨 : 스토리지의 한 영역을 분할한 것
	마운트 : 스토리지 및 디렉토리를 연결하는 것
볼륨종류 : 

	볼륨마운트
		→도커 엔진이 관리하는 영역 내에 만들어진 볼륨을 컨테이너에 디스크 형태로 마운트하는 방
		식.
		→ 직접 조작이 어려움.  따라서 ‘임시 목적의 사용’이나 ‘자주 쓰지는 않지만 지우면 안 되
		는 파일’을 두는 목적으로 사용.
	
	바인드 마운트
		→ 호스트 영역을 컨테이너에 연결하는 방식`

명령어

| 명령어                           | 설명               | 예시                                                                   |
| ----------------------------- | ---------------- | -------------------------------------------------------------------- |
| docker volume create [이름]     | 볼륨 생성            | docker volume create mysql_data                                      |
| docker volume ls              | 볼륨 목록            | docker volume ls                                                     |
| docker volume inspect [이름]    | 상세 정보            | docker volume inspect mysql_data                                     |
| docker volume rm [이름]         | 볼륨 삭제            | docker volume rm mysql_data                                          |
| docker volume prune           | 사용 안 하는 볼륨 모두 삭제 | docker volume prune                                                  |
| docker run -v [볼륨명]:[컨테이너 경로] | 컨테이너 실행시 볼륨 연결   | docker run --privileged -d -v volume_test:/vol --name test_cont test |
```
version: '3.8'

services:
  db:
    image: mysql:5.7
    volumes:
      - mysql_data:/var/lib/mysql    # 볼륨 마운트
      - ./backup:/backup            # 바인드 마운트

  web:
    image: nginx
    volumes:
      - ./html:/usr/share/nginx/html   # 바인드 마운트

volumes:
  mysql_data:          # 이름만 선언 → 자동 생성
```

백업

```
# 1. 임시 컨테이너로 볼륨 백업
docker run --rm \ -v mysql_data:/data \ -v $(pwd):/backup \ busybox \ tar czf /backup/mysql_backup.tar.gz /data
```

복구
```
# 2. 복구
docker run --rm \
  -v mysql_data:/data \
  -v $(pwd):/backup \
  busybox \
  tar xzf /backup/mysql_backup.tar.gz -C /
```

볼륨 생성
```
docker volume create [생성할 볼륨 이름]
```
기본 디렉토리 : /var/lib/docker/volumes/

볼륨과 호스트 디렉토리 연결(볼륨 링크)
```
docker run -v '볼륨 이름' : '컨테이너 내부 디렉토리 경로' --name '컨테이너 이름' '이미
지 이름'
```
**주의 호스트 디렉토리가 비어있다면 내부 디렉토리의 내용이 삭제될 수 있음.**

컨테이너 실행명령
```
docker run --privileged -d -v volume_test:/vol --name test_cont test
```
