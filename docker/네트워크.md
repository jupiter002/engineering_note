## 도커 네트워크란?

> **"컨테이너들이 서로 통신할 수 있도록 연결해주는 가상 네트워크"**

| 구분          | 설명                              |
| ----------- | ------------------------------- |
| **컨테이너 내부** | 기본적으로 **외부와 격리**                |
| **도커 네트워크** | 컨테이너 간 **이름으로 통신** 가능 (ping db) |

---

## 도커 네트워크 3가지 종류

| 종류         | 설명                       | 사용 예                        |
| ---------- | ------------------------ | --------------------------- |
| **bridge** | **기본 네트워크** (가장 많이 사용)   | docker run --network bridge |
| **host**   | 컨테이너가 **호스트 네트워크 직접 사용** | docker run --network host   |
| **none**   | 네트워크 **완전 차단**           | docker run --network none   |

> **비유**:
> 
> - bridge = 아파트 내부 LAN
> - host = 아파트 밖 공용 와이파이
> - none = 인터넷 선 뽑힘

---

## 커스텀 네트워크 만들기

bash

```
# 1. 사용자 정의 네트워크 생성
docker network create my-app-net

# 2. 확인
docker network ls
```

> **이름으로 컨테이너 연결 → db, redis 등 사용 가능**

---

## 실전 예제: **WordPress + MySQL 연동** (PPT 실습)

bash

```
# 1. 네트워크 생성
docker network create wp-net

# 2. MySQL 컨테이너 실행
docker run -d \
  --name mysql \
  --network wp-net \
  -e MYSQL_ROOT_PASSWORD=1234 \
  -e MYSQL_DATABASE=wordpress \
  mysql:5.7

# 3. WordPress 컨테이너 실행
docker run -d \
  --name wordpress \
  --network wp-net \
  -p 8080:80 \
  -e WORDPRESS_DB_HOST=mysql:3306 \
  -e WORDPRESS_DB_USER=root \
  -e WORDPRESS_DB_PASSWORD=1234 \
  wordpress:latest
```

> **핵심**: WORDPRESS_DB_HOST=mysql → **컨테이너 이름으로 접속**

## 5. 도커 네트워크 명령어 완전 정리

| 명령어                                 | 설명              | 예시                                  |
| ----------------------------------- | --------------- | ----------------------------------- |
| docker network create [이름]          | 네트워크 생성         | docker network create app-net       |
| docker network ls                   | 네트워크 목록         | docker network ls                   |
| docker network inspect [이름]         | 상세 정보           | docker network inspect wp-net       |
| docker network rm [이름]              | 네트워크 삭제         | docker network rm wp-net            |
| docker network prune                | 사용 안 하는 네트워크 삭제 | docker network prune                |
| docker network connect [net] [컨테이너] | 컨테이너 연결         | docker network connect wp-net redis |

## 6. Docker Compose에서 네트워크 사용 (자동 생성)

yaml

```
version: '3.8'

services:
  db:
    image: mysql:5.7
    networks:
      - app-network
    environment:
      MYSQL_ROOT_PASSWORD: 1234

  web:
    image: nginx
    ports:
      - "80:80"
    networks:
      - app-network
    depends_on:
      - db

networks:
  app-network:          # 자동 생성
    driver: bridge
```

> docker-compose up → app-network 자동 생성 + 컨테이너 연결

## 7. 실전 팁 & 주의사항

| 팁                              | 설명                              |
| ------------------------------ | ------------------------------- |
| **항상 커스텀 네트워크 사용**             | 기본 bridge는 이름 충돌 위험             |
| **컨테이너 이름 = 도메인**              | 같은 네트워크 내에서 ping web 가능         |
| **--network host는 보안 위험**      | 포트 충돌 주의                        |
| **윈도우/맥은 DNS 자동 설정**           | docker.for.mac.host.internal 사용 |
| **docker network prune 정기 실행** | 불필요한 네트워크 정리                    |
