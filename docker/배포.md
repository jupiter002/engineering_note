Docker의 이미지를 다른 사람들과 공유할 수 있음.

| 방법                   | 설명                          | 사용처      |
| -------------------- | --------------------------- | -------- |
| **1. 도커 허브**         | 공식 레지스트리                    | 개인, 오픈소소 |
| **2. 사내 프라이빗 레지스트리** | 회사 내부                       | 기업, 보안   |
| **3. 클라우드 레지스트리**    | AWS ECR, GCP ACR, Azure ACR | 클라우드 환경  |
| **4. 오프라인 배포**       | `.tar` 파일                   | 인터넷 없음   |
## 방법 1: **도커 허브 (Docker Hub)** 사용하기

### ① 도커 허브 계정 만들기

1. [https://hub.docker.com](https://hub.docker.com) 접속
2. **Sign up** → 이메일 인증 → 로그인
### ② 이미지에 태그 달기 (docker tag)

```
# 형식: docker tag [원본이미지] [도커허브ID]/[레포이름]:[버전]
docker tag myweb:latest myid/myweb:v1
```

> 예: docker tag nginx myuser/mynginx:v1
### ③ 도커 허브 로그인

```
docker login
# → 아이디: myid
# → 비밀번호: 입력
```
### ④ 이미지 업로드 (docker push)

```
docker push myid/myweb:v1
```
### ⑤ 다른 컴퓨터에서 사용하기 (docker pull)

```
docker pull myid/myweb:v1

# 바로 실행
docker run -d -p 8080:80 myid/myweb:v1
```


## 방법 2: **사내 프라이빗 레지스트리** 만들기

### ① 레지스트리 컨테이너 실행

```
docker run -d -p 5000:5000 --name my-registry registry:2
```
### ② 이미지 태그 + 푸시 (사내 레지스트리)

```
# 1. 태그 달기 (IP 또는 도메인 사용)
docker tag myweb:latest localhost:5000/myweb:v1

# 2. 푸시
docker push localhost:5000/myweb:v1
```
### ③ 다른 서버에서 사용

```
# 1. pull
docker pull 192.168.1.100:5000/myweb:v1

# 2. 실행
docker run -d -p 80:80 192.168.1.100:5000/myweb:v1
```

> **보안 설정 (HTTPS, 인증)**은 실무에서 필수 → registry 공식 문서 참고

## 방법 3: 클라우드 레지스트리 (AWS ECR 예시)

### ① ECR 레포지토리 생성 (AWS 콘솔)

```
myapp-repo
```

### ② AWS CLI로 로그인

```
aws ecr get-login-password --region ap-northeast-2 | docker login --username AWS --password-stdin 123456789012.dkr.ecr.ap-northeast-2.amazonaws.com
```

### ③ 푸시

```
docker tag myapp:v1 123456789012.dkr.ecr.ap-northeast-2.amazonaws.com/myapp:v1
docker push 123456789012.dkr.ecr.ap-northeast-2.amazonaws.com/myapp:v1
```

### ④ EC2 서버에서 실행

```
# 로그인 (위와 동일)
docker pull 123456789012.dkr.ecr.ap-northeast-2.amazonaws.com/myapp:v1
docker run -d -p 80:80 123456789012.dkr.ecr.ap-northeast-2.amazonaws.com/myapp:v1
```

## 실전 배포 스크립트 (자동화)

### deploy.sh (배포 서버용)

```
#!/bin/bash
IMAGE="mycompany.com/myapp:v1"

echo "이미지 pull 중..."
docker pull $IMAGE

echo "기존 컨테이너 정지 및 삭제..."
docker stop myapp-container || true
docker rm myapp-container || true

echo "새 컨테이너 실행..."
docker run -d \
  --name myapp-container \
  -p 80:80 \
  --restart unless-stopped \
  $IMAGE

echo "배포 완료!"
```

bash

```
chmod +x deploy.sh
./deploy.sh
```

## Docker Compose로 배포 (PPT 기반)

```
# docker-compose.prod.yml
version: '3.8'
services:
  app:
    image: mycompany.com/myapp:v1   # 배포용 이미지
    ports:
      - "80:80"
    restart: unless-stopped
```

bash

```
# 배포 서버에서
docker-compose -f docker-compose.prod.yml up -d
```
