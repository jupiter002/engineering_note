컨테이너는 Docker이미지로 생성하는 독립적인 가상 공간.

컨테이너 이미지 만들기
1. commit 커맨드로 컨테이너를 이미지로 변환.  ( 기존의 컨테이너를 복제하거나 이동해야 할 때 편리하게 사용. )
	docker commit 컨테이너_이름 새로운_이미지_이름

2. Dockerfile 스크립트로 이미지 만들기.
	Dockerfile은 이미지를 만드는 용으로만 사용.
	docker build -t 생성할_이미지_이름 재료_폴더_경로

컨테이너 개조

docker-compose.yml
	여러 컨테이너 + 네트워크 + 볼륨을 하나의 YAML 파일로 정의하고, 한 번에 실행/정지/삭제하는 도구

| 구분  | Dockerfile   | Docker Compose      |
| --- | ------------ | ------------------- |
| 목적  | 이미지 빌드       | 컨테이너 시스템 전체 실행      |
| 범위  | 하나의 컨테이너     | 여러 컨테이너 + 네트워크 + 볼륨 |
| 명령어 | docker build | docker-compose up   |
	기본파일구조
	```
version: '3.8'          # Compose 파일 버전 (3.8 추천)
services:               # ← 컨테이너 정의 시작
  db:                   # 서비스 이름 (임의 지정)
    image: mysql:5.7    # 사용할 이미지
    restart: always     # 컨테이너 재시작 정책
    environment:        # 환경 변수
      MYSQL_ROOT_PASSWORD: example123
      MYSQL_DATABASE: wordpress
    volumes:
      - db_data:/var/lib/mysql
  wordpress:
    image: wordpress:latest
    depends_on:
      - db              # db가 먼저 실행되어야 함
    ports:
      - "8080:80"       # 호스트:컨테이너 포트 매핑
    environment:
      WORDPRESS_DB_HOST: db:3306
      WORDPRESS_DB_USER: root
      WORDPRESS_DB_PASSWORD: example123
    volumes:
      - wp_data:/var/www/html
volumes:                # 볼륨 정의 (이름: db_data, wp_data)
  db_data:
  wp_data:
networks:               # (선택) 커스텀 네트워크
  app-network:
    driver: bridge
	```
핵심 키워드

| 키           | 설명                 | 예시                        |
| ----------- | ------------------ | ------------------------- |
| version     | Compose 파일 포맷 버전   | '3.8'                     |
| services    | 실행할 컨테이너 그룹        | db, web, redis            |
| image       | 사용할 도커 이미지         | nginx, mysql:5.7          |
| build       | Dockerfile로 이미지 빌드 | build: ./app              |
| ports       | 포트 매핑              | "3000:3000"               |
| environment | 환경 변수              | KEY: value 또는 - KEY=value |
| volumes     | 볼륨 마운트             | - ./data:/app/data        |
| depends_on  | 실행 순서 제어           | depends_on: [db]          |
| restart     | 재시작 정책             | always, unless-stopped    |
| networks    | 네트워크 정의            | driver: bridge            |

자주 쓰는 명령어

| 명령어                          | 설명                      |
| ---------------------------- | ----------------------- |
| docker-compose up            | 정의된 모든 컨테이너 실행          |
| docker-compose up -d         | 백그라운드 실행                |
| docker-compose down          | 컨테이너 + 네트워크 삭제 (볼륨은 유지) |
| docker-compose down -v       | 볼륨도 함께 삭제               |
| docker-compose logs          | 로그 확인                   |
| docker-compose ps            | 실행 중인 컨테이너 목록           |
| docker-compose exec app bash | 컨테이너 내부로 진입             |
