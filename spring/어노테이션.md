코드에 붙이는 **메타 데이터** 이며, 스프링 컨테이너가 리플렉션, 프록시, 핸들러를 통해 런타임 실행시 자동으로 **메타 데이터** ( Bean 생성, DI, 트랜잭션, 웹 매핑 )에 관련된 기능을 수행하도록 하는 도구이다.

> **Tip**:  
> - `@Component` 계열 (`@Service`, `@Repository`, `@Controller`)은 모두 `@Component`의 특수화된 형태입니다.  
> - `@Autowired`는 생성자 주입을 권장하며, 필드 주입은 지양하는 것이 좋습니다.  
> - `@Transactional`은 **서비스 계층**에 두는 것이 일반적입니다.


어노테이션 예제
```java
@ComponentScan("com.example")
@SpringBootApplication
public class DemoApplication { ... }

@Service
@Transactional
class OrderService {

    private final OrderRepository repo;

    @Autowired                // 생성자 주입 권장
    public OrderService(OrderRepository repo) { this.repo = repo; }

    @Transactional(readOnly = true)
    public Order find(Long id) { return repo.findById(id); }
}
```
	1. @ComponentScan → OrderService 클래스 스캔
	2. @Service → BeanDefinition 등록
	3. @Transactional → Proxy 생성 (트랜잭션 시작/종료)
	4. @Autowired → 생성자 파라미터 OrderRepository 주입
