함수는 하나의 특별한 목적의 작업을 수행하도록 설계된 독립 블록이다.

함수를 사용하는 가장 큰 이유는 반복적인 코드를 줄이기 위해 사용한다.
```php
function 함수이름(매개변수1, 매개변수2,...)
{  
    함수가 호출 되었을 때 실행될 코드;  
}
```
	함수의 이름은 문자,숫자,_기호만 사용할 수 있다.
	함수의 이름은 숫자로 시작할 수 없다.
	함수이름을 중복으로 사용할 수 없다.

함수 호출
```PHP
$sum = sum(1, 2); // 함수 sum()을 호출하면서, 인수로 1과 2를 전달함.
                  // 함수의 호출이 끝난 뒤에는, 반환값을 변수 $sum에 대입함.
```
함수 값 반환
	함수는 return키워드를 사용해 함수 블록 내에서 실행된 코드의 결과를 반환할 수 있다.
	반환문은 배열, 연관배열, 문자열 등 모든 타입의 데이터를 반환할 수 있다.
```php
function sum($x, $y) // 함수의 이름은 sum()이며, 변수 x, y를 매개변수로 가지는 함수를 정의함.

{  
    return $x + $y;  // 매개변수 x, y를 더한 값을 반환함.  
}  
echo sum(1, 2);      // sum() 함수에 숫자 1와 2을 인수로 전달하여 호출함.
```

php7부터는 반환값을 반환받기 원하는 타입으로 지정할 수 있다. 또한 타입을 지정할 때 강도도 지정할 수 있다. 약한 강도에서는 타입이 불일치하면, 자동으로 타입 변환을 통해 명시된 타입으로 변환해준다.
강한 강도에서는 반환값의 타입이 일치하지 않으면, 오류를 발생시킨다.
```php
//약한 강도
function sun($x, $y) : float{
	return $x + $y;
}
var_dump(sum(3+4)); //float

//강한 강도
declare(strict_types=1); //strict mode

function sum($x, $y) : float{
	return $x + $y;
}
var_dump(sum(3+4)); // 오류발생
var_dump(sum(3+4.5)); //float
```
매개변수, 인수
인수는 함수를 호출할 때 전달하는 값이다. 변수가 될 수도 있고, 고정값이 될 수도 있다.
매개변수는 함수로 전달하는 인수가 함수내에서 활용될 수 있게 매개체가 되는 변수다.

매개변수의 전달 방식에는 두 가지가 있다.
1. 값 전달 방식
2. 참조 전달 방식

	값 전달
```php
function increment($para) {  
	$para++; // $value의 값을 복사하여 increment() 함수에 인수로 전달함.  
}  
$value = 1;  
increment($value);
```
	인수를 함수에 전달하면, 새 매개변수에 전달받은 값이 복사되서 저장된다.
	매개변수에 저장된 값은 데이터의 복사본으로, 함수 안에서 변경되도 원본 데이터에는 영향을 미
	치지 않는다.
	
	참조 전달
```php
	function increment(&$para) // 인수로 전달되는 값의 원본을 참조함.  
	{  
	    $para++;  
	}  
	$value = 1;  
	increment($value);
```
	함수 내부에서 함수 밖의 데이터를 조작하려면 해당 변수를 전역 변수로 선언할 수도 있다.
	하지만 참조 전달을 한다면 유연한 코드를 작성할 수도 있다.
	참조 전달은 인수로 전달받은 값을 복사하는게 아니라, 전달받은 원본 데이터에 대한 참조 변수
	를 매개변수에 전달한다. 따라서 함수 내부에서 값을 변경하면, 함수 밖의 원본 데이터도 같이 바
	뀌게 된다.

	기본 매개변수
	함수를 호출할 때 명시된 매개변수를 전달하지 않았을 때 사용할 기본값을 의미한다.
	함수를 호출할 때 정의되어 있는 매개변수 수만큼 전달하지 않으면, php파서가 오류를 발생시키는
	데, 기본 매개변수를 설정하면, 함수 호출시 인수의 개수를 유연하게 설정할 수 있다.
```php
	function sum($value1, $value2=0, $value3=0){
		 return $value1 + $value2 + $value3;
	}
	echo sum(1,2,3); //6
	echo sum(1,2); //3
	echo sum(1); //1
	echo sum(); //오류 발생
```
	php에서 함수에 매개변수를 전달할 때는 매개변수의 왼쪽부터 차례대로 대입되기 때문에
	$value3에 값을 전달하려면 $value1, $value2부터 값을 전달해야한다.
	기본 매개변수의 설정은 매개변수 리스트의 맨 오른쪽 끝 매개변수부터 시작한다.

	가변 길이 인수 목록
	php5.5이하에서는 func_num_args(), func_get_arg(), func_get_args()함수를 사용해 설정
	할 수 있다.
```php
	function sum()
	{  
	    $sum = 0;  
	    foreach(func_get_args() as $n) { // PHP 5.5 이하  
	        $sum += $n;  
	    }  
	    return $sum;  
	}
```
	php5.6이상에서는 ...토큰을 사용해 설정할 수 있어 간편하다.
```php
	function sum(...$num) // PHP 5.6 이상
	{  
	    $sum = 0;  
	    foreach($num as $n) {  
	        $sum += $n;  
	    }  
	    return $sum;  
	}
```
php에서는 함수안의 함수를 생성할 수 있다.
php에서 모든 함수는 전역 함수이므로, 함수 내부에서 선언된 함수라도 해당 함수 외부에서 호출할 수 있다.

```php
function out()  
{  
    function in()  
    {  
        echo "이제 함수를 사용할 수 있습니다";  
    }  
}

//in(); // 이 부분은 in() 함수가 선언되기 전이므로, 함수를 호출할 수 없습니다.  
out();

in();   // 이 부분은 in() 함수가 선언되었으므로, 함수를 호출할 수 있습니다.
```
out()안에 in()이 정의되어 있기 때문에 out()을 호출하기 전에는 in()을 호출할 수 없다.
