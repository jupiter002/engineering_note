dom은 자바스크립트가 html요소에 접근하기 위한 인터페이스다.
![[Pasted image 20250703083132.png]]
html은 노드라는 계측적 구조에 데이터를 저장한다.
노드들은 모두 계층적 관계를 맺으며, 최상위에는 하나의 상위 루트 노드가 존재(html).
루트 노드를 제외하고, 모든 노드는 하나의 부모 노드만 가진다.

조상 노드 - 부모 노드 포함, 계층적으로 본인보다 상위에 존재하는 모든 노드.
형제 - 본인이랑 같은 부모 노드를 가지는 모든 노드.
자손 - 본인 포함, 계층적으로 본인보다 하위에 존재하는 모든 노드.

아래와 같은 프로퍼티로 노드에 접근할 수 있다.

- 노드 간의 관계를 통해접근
1. parentNode : 부모 노드

2. childNodes : 자식 노드 리스트

3. firstChild : 첫 번째 자식 노드

4. lastChild : 마지막 자식 노드

5. nextSibling : 다음 형제 노드

6. previousSibling : 이전 형제 노드

- 노드에 대한 정보에 접근
1. nodeName
	- 문서 노드 (#document)
	- 요소 노드 (태그 이름 (영 대문자))
	- 속성 노드 (속성 이름)
	- 텍스트 노드 (#text)
2. nodeValue
	- 요소 노드 (undefined)
	- 속성 노드 (해당 속성의 속성값)
	- 텍스트 노드 (해당 텍스트 문자열)
3. nodeType
	- 요소 노드 (1)
	- 속성 노드 (2)
	- 텍스트 노드 (3)
	- 주석 노드 (8)
	- 문서 노드 (9)

node list
	getElementsByTagName()메소드나 childNodes 프로퍼티의 값으로 반환되는 객체.
	인덱스를 이용하여 접근 가능
	
	각 요소 노드 다음에는 별도의 텍스트 노드가 존재한다. 인덱싱은 1, 3, 5 같이 홀수로 인덱싱

노드 추가
	appendChild() - 새 노드를 해당 노드의 자식 노드로 맨 마지막에 추가
	insertBefore() - 새 노드를 특정 자식 노드 앞에 추가
		부모 노드.insertBefore(새로운 자식노드, 기준 자식노드);
	insertData() - 텍스트 노드의 데이터에 새 텍스트 추가
		텍스트노드.inserData(오프셋, 새 텍스트);
		
노드 생성
	createElement() - 새 요소 노드를 생성
	createAttribute() - 새 속성 노드 생성
		같은 이름의 속성 노드가 존재하면, 새로 생성하는 노드로 대체됨.
		이미 존재하는 요소 노드에 속성 노드를 생성하려면 setAttribute()
	createTextNode() - 새로운 텍스트 노드를 생성
	
노드 제거
	removeChild() - 자식 노드 리스트에서 특정 자식 노드를 제거
		성공적으로 제거시, 제거된 노드를 반환.
		제거되는 노드의 자식 노드들도 같이 제거.
	removeAttribute() - 속성 이름으로 특정 속성 노드를 제거
	
노드 복제
	cloneNode() - 기존의 존재하는 노드를 똑같이 복제
		복제할 노드.cloneNode(자식노드복제여부(boolean));
		
노드 값 변경
	nodeValue - 텍스트 노드 값 변경
		기준노드.nodeValue()
	setAttribute() - 속성값을 변경하려는 속성이 없으면, 속성을 생성 후 값 저장

요소 노드 교체
	replaceChild() - 기존의 요소 노드를 새 요소 노드로 교체
		부모노드.replaceChild(새 자식노드, 기존 자식노드);

텍스트 노드 데이터 교체
	replaceData() - 텍스트 데이터 교체
		텍스트노드.replaceData(오프셋, 교체할 문자수, 새 데이터);
