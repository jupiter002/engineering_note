브라우저가 알려주는 html요소에 대한 사건의 발생
웹에서 사용된 자바스크립트는 이벤트에 반응하여 특정 동작을 수행 가능

이벤트 타입
	키보드, 마우스, html dom, window객체 등을 처리하는 이벤트가 존재.

이벤트 명세
	DOM Level 3 이벤트 명세
	HTML5 관련 이벤트 명세
	모바일 장치를 위한 이벤트 명세

이벤트 객체
	해당 타입의 이벤트에 대한 상세 정보를 저장하고 있다.
	type프로퍼티, target프로퍼티를 가지고 있다.
	이 객체는 이벤트 리스너가 호출될 때 인수로 전달됨.

이벤트 리스너 등록
	자바스크립트에서 프로퍼티로 등록
		window.onload = function(){
			~~~~~~~~
		}; - 페이지가 로드되었을 때 동작 수행

	html 태그에 속성으로 등록
		<p onclick="alert(~~~~~);"></p>
		
	객체나 요소의 메소드에 이벤트 리스너 전달
		addEventListener() - 
			대상객체 - addEventListener(이벤트명, 실행할 이벤트 리스너, 이벤트 전파 방식);
			1. 이벤트 명 : 이벤트 리스너를 등록할 이벤트 타입을 문자열로 전달.
			2. 실행할 이벤트 리스너 : 지정된 이벤트가 발생했을 때 실행할 이벤트 리스너를 전달.
			3. 이벤트 전파 방식 : false - 버블링, true - 캡쳐링
		attachEvent() - 구 버전 브라우저에서 사용.

이벤트 호출 순서 <- 잘 이해 안됐음 (20250703) 사용 예시 참고 필요 
	하나의 이벤트 타입에 여러 개의 이벤트 리스너를 등록할 수 있다.
	
	1. 이벤트의 대상이 되는 객체나 요소에 프로퍼티로 등록한 이벤트 리스너를 가장 먼저 호출.
	2. 그 후 addEventListener()를 사용해 등록한 이벤트 리스너를 등록한 순서대로 호출.
	
이벤트 리스너 삭제
	removeEventListener() - 등록한 이벤트 리스너를 삭제
		이벤트의 삭제를 유도할 객체.removeEventListener(이벤트명, 대상객체)

이벤트 전파
	이벤트가 발생했을 때, 브라우저가 이벤트 리스너를 실행시킬 대상 요소를 선택하는 과정
	
	window객체 같은 단일 객체의 이벤트 전파는 발생하지 않음.
	하지만 document객체나 html문서의 요소에서 이벤트가 일어나면 대상 요소를 선택하기 위해 이벤트 전파 발생

	버블링 - 이벤트가 발생한 요소부터 DOM트리를 따라 위쪽으로 올라가는 전파 방식
	이벤트 발생지점 -> 부모 요소1,2,3-> document객체 -> window 객체

	캡쳐링 - 이벤트 발생한 요소부터 DOM트리의 최상위부터 아래쪽으로 내려가는 전파 방식
	window객체가 실행된 후, document객체에 등록된 리스너가 실행, 그 후에 자식 요소에 등록된 리스너가 실행.
	실제 이벤트의 대상이 되는 요소에 이벤트가 전달되기 전에 상위 요소에 등록된 이벤트 리스너가 가로챌 수 있음.

이벤트 기본 동작의 취소
	a태그를 클릭하면 지정된 주소를 따라가 새로운 페이지를 열게 되는 기본 동작이 있다.
	preventDefault(), returnValue프로퍼티를 이용하면 이런 기본 동작의 실행을 취소할 수 있음.

이벤트 전파의 취소
	stopPropagtion(), cancelBubble프로퍼티를 이용하면 이벤트 전파도 취소할 수 있음.

동적 로그 및 이벤트 바인딩
	부모 화면에서 ajax로 가져오는 도중에 스크립트 태그가 누락되거나 직접적인 on('click', )방식이 적용되지 않을 수 있음.

	이를 해결하려면 부모 화면에서 이벤트 위임을 사용해 한번만 선언하는 것이다.
```javascript
// 부모 화면의 스크립트 태그 안
$(document).on('click', '.coupon_download', function() {
,,,

}
```
