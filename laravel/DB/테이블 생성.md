라라벨은 Eloquent라는 ORM을 사용하고 있다.

Eloquent덕분에 복잡한 쿼리문을 사용하지 않고 간단한 명령문들로 DB에 대한 작업을 진행할 수 있다.

테이블 생성
	클래스파일 생성docker - 
		./vendor/bin/sail artisan make:migration create_example_table
	데이터베이스 마이그레이션 -
		./vendor/bin/sail artisan migrate
	db 확인 -
		./vendor/bin/sail mysql -uroot
	스키마 목록 확인 -
		show databases;
	확인할 스키마 지정
		use exaple_schema;
	테이블 구조 확인
		desc example_table;
더미 데이터 추가
	./database/seeders/DatabaseSeeder.php에서
		(factory클래스가 준비되어 있다면) example_table::factory(num)->create();
		
		(factory클래스가 준비되어 있지 않다면)
		example_table::factory()->create([
		'column_name' => 'Test User1',
		'column_name' => 'dummy data'
		])
	db에 데이터 insert -
		./vendor/bin/sail artisan db:seed
db롤백
	./vendor/bin/sail artisan refresh
rollback, migrate, seed 한번에
	./vendor/bin/sail artisan migrate:refresh --seed
	순서 : rollback -> migrate -> seed
