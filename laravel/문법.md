레이아웃 설정

공통 페이지
```php
//layout.php
<head>
	~~~
	<title>@yield('title')</title> //타이틀명 영역
	<link rel"stylesheet" href="{{url('css/site.css')}}">
</head>
<div>
	//content 영역 연결
	@yield('content')
</div>
```
콘텐츠 페이지
```php
//board.php, myPage.php등등
@extends('layout') //레이아웃 영역 연결
@section('title', 'board') //페이지 별 타이틀 명 지정

@section('content') //콘텐츠 영역 명시
	<div>
		~~~~
	</div>
@endsection
```

class생성
	터미널 창에서 명령문 입력
	- 컨트롤러
		php artisan make:controller
		~Controller
		
Route 디렉토리에서 컨트롤러 연결
```php
use App\Http\Controllers\~Controller;
Route::get('/~~~', [~Controller::class, '~~~']);
```
	

컨트롤러에서 뷰 페이지 반환
```php
class ~Controller extends Controller
{
	public function index(){
		return view('example')
	}
}
```

뷰 페이지에서 php변수 사용
```php
{{$bike}} //중괄호 2개 안에 함수 및 변수 사용
<a href="{{route('bikes.show')}}"></a>
```

url라우팅명 지정
/Route/web.php
```php
Route::get('/user/profile', [UserController::class, 'show'])->name('profile');
//뷰 페이지에서 사용할 라우팅명 지정
```
/resources/views/~.php
```php
<body>
	<a href="{{route('profile')}}">Profile</a> //web.php에서 선언한 라우팅명
</body>
```
링크에 인수 전달
```php
<a href="{{route('bikes.show', ['bike'=>$bike['id']])}}"></a>
```
