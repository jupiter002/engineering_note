컴포넌트를 생성하면 레거시에서 inlcude하는 것처럼 파일을 다룰 수 있다.
header, footer또는 Alert, Alram등 어플리케이션 전반적으로 사용하는 파일은 컴포넌트로 생성하는 게 편리하다.

컴포넌트 클래스 생성
laravel -
	php artisan make:component Alert
docker - 
	./vendor/bin/sail make:component Alert
생성지점
	./resources/Components

./resources/Components
```php
<?php
 
namespace App\View\Components;
 
use Illuminate\View\Component;
use Illuminate\Support\Facades\DB;
use Illuminate\Support\Facades\Auth;
 
class Alert extends Component
{
	//
    //...(생략)...
    //
    public function render()
    {
        $noticeAlert = DB::table('users')
                        ->where('user_id', Auth::user()->user_id)
                        ->first();
 
        return view('components.alert')->with([
            'noticeAlert' => $noticeAlert
        ]);
    }
}
```
./resources/views
```php
<!-- 생략 -->|
</head>|
<body>|
@include('partials/header')|
<x-alert/> <!-- x-컴포넌트명(소문자) -->
```
./resources/views/Components/alert.blade.php
```php
@if ($noticeAlert->notice_read == 'n')
	<div>
		<span>읽지 않은 공지사항이 있습니다.</span>
	</div>
@endif
```
