설치 -
	리눅스 환경 - /bin/bash -c "$(curl -fsSL https://php.new/install/linux/8.4)"
	apt update
	apt-get upgrade

프로젝트 생성 - 
	laravel new example-app 또는 composer create-project laravel/laravel 
	example-app
프론트엔드 설정
	react, vue, livewire( laravel 내장 프레임워크 ), none
테스트 프레임워크 설정
	phpunit, pest
db선택
	MySQL, PostgreSQL, SQLite, SQL Server
	
개발서버 실행 - 
	php artisan serve

운영서버 실행 -
	apache 가상호스트 설정
		/etc/apache2/site-available/example-app.conf 생성
	심볼릭 링크 생성
		sudo a2enstie example-app
